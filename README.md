# Pet Fitness

A React Native (Expo) entry screen for the **Pet Fitness** mobile experience. It offers polished social login choices plus sign-in and sign-up actions on a dark gradient hero layout.

## Getting started

1. Install dependencies
   ```bash
   npm install
   ```
2. Start the Expo dev server
   ```bash
   npm run start
   ```
3. Follow the Expo CLI prompts to open the app on iOS, Android, or web.

## Screen details

- Connect with Google
- Connect with Facebook
- Sign in
- Create account (sign up)

The layout highlights the Pet Fitness brand, warm copy, and a motivational footer to keep pet workouts fun and consistent.

## Assets

Project assets are left to the Expo defaults so the repository stays binary-free (to avoid PR tooling errors). If you want custom icons or splash screens, add PNGs to an `assets/` folder and point to them from `app.json`.
